# Rentify — Local Item Rental Platform

Pakistan's first peer-to-peer local item rental platform built with MERN Stack.

## Tech Stack
- **Frontend:** React.js + Material UI + Vite
- **Backend:** Node.js + Express.js
- **Database:** MongoDB Atlas
- **Real-time:** Socket.io
- **Auth:** JWT + bcrypt
- **Images:** Cloudinary

## Features
- User Authentication (Register/Login with JWT)
- CNIC Verification + Digital Rental Agreement
- Item Listing with Photos
- Browse + Search + Filter by Category
- Booking Request System (Approve/Reject)
- Real-time Chat (Socket.io)
- Review & Rating System
- Owner & Renter Dashboard
- Mobile Responsive UI

## Setup Instructions

### Backend:
```bash
cd server
npm install
```

Create `.env` file:
```
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```

```bash
npm run dev
```

### Frontend:
```bash
cd vite-project
npm install
npm run dev
```
